# Identidad visual

Coloque aquí los archivos corporativos originales antes de compilar:

- `icon.ico`: icono multirresolución de Windows (16, 32, 48 y 256 px).
- `logo.png`: logo original, preferiblemente con fondo transparente.

La aplicación usa un monograma tipográfico temporal cuando estos archivos no están presentes; no se inventa ni altera el logo de la empresa.
